[h1]Content Tool[/h1]

[b]Content Tool adds nothing new to the game by itself.[/b] It is a tool for modders. Other mods use it to add or change game assets. Installed alone, it changes nothing.

[b]Problems and suggestions go only to GitHub Issues:[/b] [url=https://github.com/UberMorgott/PhoenixPoint-Mod-ContentTool/issues]github.com/UberMorgott/PhoenixPoint-Mod-ContentTool/issues[/url]
Steam comments are not used for bug reports or requests.

[h2]What it can do[/h2]
[list]
[*]Replace shipped textures, meshes (.obj, .glb), material values, animation curve scaling and videos.
[*]Replace shipped sounds with your own .wav, .ogg or .mp3 files.
[*]Add new assets under new Addressables keys: textures, models, meshes, materials, animation clips. Add new videos.
[*]Add new weapons cloned from shipped ones, creatures with custom models, new character bodies and playable humanoid soldiers.
[*]Works in memory while the game runs. It never writes to the game installation.
[*]ct_* console commands: import, bake and check a content project, bake sound banks, stage a mod folder for publishing.
[*]ct_* console commands: search shipped bundles, assets, sounds, definitions, bones and material properties; export shipped textures, meshes, videos and sounds.
[*]ct_fit: move, rotate and scale a weapon in the hand and save the fit to the mod's ppcontent.json.
[*]In-game bench (Ctrl+Alt+B on the geoscape): replace a model with a bone check, fit a weapon, add a weapon, sounds, videos, build and share.
[*]package.ps1 builds a publishable mod folder with the game closed.
[*]Demo projects are on GitHub, linked from the documentation.
[/list]

[h2]Installing[/h2]
Subscribe, open Mods in the main menu and enable Content Tool. Mods that need it list it as a dependency. No other requirements.
