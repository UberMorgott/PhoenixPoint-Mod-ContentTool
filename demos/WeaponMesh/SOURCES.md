- `tools\source\Gun_Rifle.gltf` + `Gun_Rifle.bin` — the file exactly as downloaded, so the fit is
  reproducible. 5554 vertices, 6194 triangles, one material, no armature.
- `Content\Meshes\rifle.glb` — the same geometry, fitted into the shipped weapon's local box by
  `tools\fit_rifle.py`. Derived work of a CC0 asset; also CC0.

## The albedo

- `Content\Textures\rifle_albedo.png` — Quaternius' `T_Guns_Batch1_BaseColor.png` (2048x2048),
  downscaled to 1024 and recoloured by `tools\grimdark.ps1`. Pixel-for-pixel: the UV layout is
  untouched, only the colours move. CC0, same as the original.
- The kit's `T_Guns_Batch1_Normal.png` and `T_Guns_Batch1_ORM.png` are **not** shipped. See the
  README for why they would be dead files here.

## The neutral maps

`Content\Textures\rifle_*_flat.png`, `rifle_occlusion_white.png`, `rifle_emissive_off.png` are four
solid 4x4 colours generated by `tools\make_neutral_maps.py`. Not anyone's art.

## Phoenix Point's own assets

Nothing of Snapshot Games' is redistributed here. The mod names shipped objects by name, and
ContentTool builds a patched copy of the player's own `px_equipment_assets_all.bundle` under its
AppData folder (`…\Phoenix Point\ContentTool\Patched\<installTag>\<modId>\`). The shipped bundle
itself is only read.
